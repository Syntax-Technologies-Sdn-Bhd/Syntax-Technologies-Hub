## 最值得先研究的 3 个

1. **AMS**：小红书 10K+，比 Syntax 高一个级别，而且题材几乎一样（e-Invoice、SQL 设置教学）。之前看到它的置顶帖「e-invoice开始了，SQL 3步设置至提交」有 1,276 个互动。可以研究它的标题和教学帖格式。
2. **AutoCount**：客户拿 SQL 比较时最常比的就是它。FB 39,525、IG 2,287，IG 比所有 SQL 经销商都大。看它怎么讲 e-Invoice 和「Beyond Accounting Software」的定位。
3. **StoreHub**：同样卖给马来西亚老板，FB 299,196。官网有「Request a demo」和专门的 e-Invoicing 落地页，跟 Syntax「问价 → 约 demo」的成交流程最像。
